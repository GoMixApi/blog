DeepSeek Harness RC8: Subagents, Parallel Tasks, and Multimodal Commands

Published: 2026-08-27 · Category: Integration Guide · Updated: 2026-08-27

DeepSeek Harness continues to iterate fast. The RC8 pre-release introduces three major upgrades: Claude and Codex as subagents, parallel task execution, and multimodal command input. Here's what changed and how GoMixAPI fits into the stack.

1. Claude and Codex as Subagents

DSH can now treat Claude and Codex as subagents—installed on demand, dynamically scheduled, and run as needed. This means you can use top-tier overseas coding agents as workers inside a Chinese open-source framework.

  • Install only when needed, no resource waste
  • Parallel task flows without blocking each other
  • Delegate specific tasks to the most capable model

For teams using DSH, GoMixAPI provides the unified model layer underneath—one key to access 20+ Chinese models, plus compatibility with external agents like Codex.

2. Unattended Background Mode for Codex

Codex now supports unattended background running—tasks enter a queue and execute automatically without manual monitoring. Long-running automation becomes truly hands-off.

This is ideal for batch processing, scheduled reports, and other long-horizon tasks. When paired with GoMixAPI's Singapore-native low latency, those background jobs complete faster for SEA-based teams.

3. Multimodal Commands: Screenshots and Images

Core commands like /goal and /plan can now accept screenshots and images. The @ menu also supports referencing local files and past sessions.

  • Take a screenshot and set it as the goal
  • Attach an image to provide visual context for planning
  • Reference local files and session history in commands

Important note: DSH has opened the image channel, but the underlying model must have vision capability. GoMixAPI includes multimodal models like Dola Seed-2.0 series that can handle image inputs—so you can actually use this feature end-to-end without switching platforms.

What Makes DSH Different: The Cordis Kernel

DSH is built on Cordis, a microkernel plugin system. In DSH, everything is a plugin: model adapters, tools, session storage, agent loops, even UI components. This means you can assemble an agent like building blocks — swap a model, add a tool, or replace a storage backend without touching core code.

The official design philosophy is simple: "Everything is a Plugin." This gives developers two powerful capabilities:

  • Temporal composability: Uninstall a plugin and its effects are cleanly removed, restoring the project to its previous state.
  • Spatial composability: When a dependency changes, Cordis automatically re-resolves relationships between plugins, pausing or resuming them as needed.

Plugin Ecosystem: Reuse Community Knowledge

The real power of DSH is its growing open-source plugin community. Instead of coding every capability yourself, you can install plugins from GitHub and combine them into your agent. For example:

  • Vision plugins for image understanding when your base model is text-only
  • Accounting plugins for extracting and logging expense data
  • Course generation plugins that create interactive learning experiences

This means individual developers can share new capabilities with the entire community, accelerating innovation far beyond what any single company could achieve.

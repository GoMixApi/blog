How to Run DeepSeek Harness with GoMixAPI: Step-by-Step Guide

Published: 2026-08-17 · Category: Tutorial · Updated: 2026-08-17

What you'll build: A working DeepSeek Harness Agent environment connected to 20+ Chinese LLMs (DeepSeek, Qwen, Dola, GLM, Hunyuan, Kimi) through one GoMixAPI key.

Requirements: Node.js 22+ · GoMixAPI account · Basic terminal knowledge

Step 1: Get Your GoMixAPI API Key

  1. Sign up at gomixapi.com
  2. Verify your email and log in to the console
  3. Go to Token Management and create a new API key
  4. Copy your key — it starts with sk-. You'll get 5,000 free test tokens.

Step 2: Install DeepSeek Harness

DSH requires Node.js 22 or higher. Check your version:

node -v

If it's below 22, install Node 22 via nvm:

curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
source ~/.bashrc
nvm install 22
nvm use 22

Then install DSH:

npm install @deepseek-ai/dsh

Step 3: Import GoMixAPI Profile

We published a ready-to-use profile on GitHub. Clone it and import:

git clone https://github.com/GoMixApi/dsh-profile
cd dsh-profile
export GOMIXAPI_API_KEY="sk-your-key"
npx @deepseek-ai/dsh web --profile gomixapi.profile.json

DSH will start a local Web UI at http://127.0.0.1:3080. Open it in your browser.

Step 4: Verify the Connection

In the DSH Web UI:

  1. Open model selector
  2. Choose provider GoMixAPI
  3. Pick any model, e.g. deepseek-v4-flash-202605
  4. Type "Say hello" in the input box
  5. You should see a response within seconds

Step 5: Switch Between 20 Models

All 20 models are available through the same key. Simply switch the model in the selector. No code changes needed.

Popular choices:

  • deepseek-v4-flash-202605 — fastest, cost-effective
  • dola-Seed-2.0-pro — multimodal Agent, audio
  • kimi-k3 — deep reasoning, 1M context
  • qwen3.7-plus — enterprise production

Step 6: Run Your First Agent Task

Try a simple coding task in DSH:

Write a Python function to check if a string is a palindrome.

DSH will execute the task using your selected model. You can see the full trajectory — every tool call, every response — in the trajectory view.

Troubleshooting

MISSING_CREDENTIAL

Means the API key wasn't loaded. Make sure you ran export GOMIXAPI_API_KEY="sk-your-key" before starting DSH.

UNKNOWN_MODEL

The model ID doesn't match our catalog. Check the exact ID in the compatibility matrix above.

Node version errors

If you see errors about createZstdDecompress or Promise.withResolvers, your Node.js is below 22. Upgrade via nvm as shown in Step 2.
